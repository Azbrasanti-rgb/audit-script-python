Sobre este proyecto

Este repositorio fue creado porque mi pareja necesitaba ayuda con su trabajo y quise facilitarle las cosas con este script. Aunque es un flujo de trabajo muy básico, resulta sumamente útil: supera las limitaciones de Excel, el cual requería un llenado casi manual (con fórmulas, arrastres y otros pasos) y tomaba el doble del tiempo que este proceso automatizado.
Como indica el título, esta es la versión 1.0. Aún tengo pendiente integrar librerías como Pandas para hacerlo aún más efectivo y rápido, aunque esta primera versión ya funciona de manera excelente.
